Malatya Turgut Özal Üniversitesi'nde yazılım mühendisliği 4. sınıf öğrencisiyim. Teorik bilgisayar bilimleri altyapımı modern yazılım prensipleriyle birleştirip gerçek dünya problemlerine çözüm üretmeye odaklanıyorum.

          
Benim için iyi kod, sadece çalışan değil; okunabilen ve yıllar sonra da sürdürülebilen koddur. Yapay zeka odaklı stajımda bir sohbet botu ve akıllı envanter sistemi geliştirdim; üniversitede de mobil ve web projelerinde ekip çalışması yürütüyorum. Teorik bilgimi dinamik bir ekipte pratiğe dönüştürmeye hazırım.

Akıllı Envanter ve Stok Yönetim Sistemi

            
Stokların doğal dille yönetilebildiği bir depo yönetim sistemi. .NET 9 Web API ve MS SQL Server üzerinde katmanlı mimariyle kurdum; React yönetim paneli, JWT ile rol bazlı yetkilendirme ve kritik stok takibi içeriyor. Yapay zeka asistanı stokları sorgulayabiliyor, stoğu değiştiren işlemleri ise kullanıcı onayına sunuyor. MCP sunucusu sayesinde Claude Desktop'tan da kullanılabiliyor.

            
  • C#
  • .NET 9
  • MS SQL + Dapper
  • React + TypeScript
  • JWT
  • MCP
